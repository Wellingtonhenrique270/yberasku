📘 Guia Rápido

Estrutura do SKU

UNIDADE → MARCA-LINHA-CATEGORIA-TAMANHO-[COMPOSIÇÃO]
KIT → KIT-MARCA-LINHA-[TAMANHO]-[COMPOSIÇÃO]-[FAMÍLIA]-NPC
CAIXA → CX-MARCA-LINHA-[TAMANHO]-[COMPOSIÇÃO]-NPC

Itens entre colchetes só entram no SKU se o campo for preenchido. A Composição agora é uma lista pré-definida, igual a Marca/Linha/Categoria/Tamanho — os códigos já vêm prontos para o SKU (ex: SH + MSK + TN → SHMSKTN), sem precisar digitar toda vez.

Exemplos

FG-100T-SH-250Fashion Gold · 100 Timetros · Shampoo · 250ml (sem composição)
FG-100T-SH-250-CLGMesmo item, com Composição "CLG" agregada ao SKU
KIT-FG-100T-DUO-3PCKit Duo com 3 peças, sem tamanho/composição definidos
KIT-YB-VELL-250-SHMSKSR-DUO-3PCKit com Tamanho "250" e Composição "SH+MSK+SR"
CX-FG-100T-12PCCaixa fechada com 12 unidades

Regras importantes

  • ✅ SKUs duplicados são bloqueados automaticamente na criação
  • ✅ Tamanho e Composição agora entram no código do SKU em qualquer tipo (Unidade, Kit ou Caixa), quando preenchidos
  • ✅ Composição agora é uma lista gerenciável (igual Marca/Linha/Categoria/Tamanho) — adicione ou remova combinações em Gerenciar Listas
  • 🕒 Todo SKU gerado guarda automaticamente quem criou e a data/hora exata da criação, visíveis nas colunas "Criado por" e "Criado em" da Base de SKUs
  • ✅ KIT e CAIXA exigem o número de peças preenchido (inteiro maior que zero)
  • ✅ Campo Promo é apenas referência e pode ser editado depois (botão ✏️ na Base de SKUs)
  • ⚠️ Composição não pode ser editada depois de gerado o SKU, pois já faz parte do código — para mudar, remova e gere novamente
  • 🏷️ Itens marcados como LEGADO foram importados de antes deste sistema e podem não seguir o padrão de nomenclatura atual — revise antes de usar como referência
  • 📦 Itens marcados como IMPORTADO vêm da planilha real de produtos da Ybera USA (1074 SKUs) — servem só para o sistema nunca gerar um código repetido, não podem ser editados/removidos e não entram nas listas de Marca/Linha/Categoria/Tamanho
  • ❌ Não é possível editar o código do SKU nem os campos que o formam (marca, linha, categoria, tamanho, tipo, peças); remova e gere novamente se precisar mudá-los

📦 Base real de produtos

Este sistema já vem com os 1074 SKUs únicos extraídos da planilha de produtos e da exportação da loja da Ybera USA. Eles aparecem na Base de SKUs com o tipo IMPORTADO e o nome do produto original na coluna "Produto / Referência". A única função deles aqui é garantir que nenhum SKU novo gerado neste sistema colida com um código já usado de verdade — mesmo os que não seguem o padrão MARCA-LINHA-CATEGORIA (ex: nomes de promoção como Fashion150 ou SORVETE-B).

⚡ Modo "menor SKU possível"

Com o checkbox "Sempre gerar o menor código de SKU possível" marcado (ativado por padrão), o sistema testa remover Composição, depois Tamanho e, em Kits, também a Família — sempre um bloco por vez — e mantém a remoção somente se o resultado continuar único na base. Assim que remover mais um bloco causaria colisão com um SKU já existente, ele para e usa a última versão (mais curta) que ainda é exclusiva. Desmarque o checkbox se preferir sempre o SKU completo, com todos os campos preenchidos.

👤 Usuários

Quem é administrador (como o admin padrão) enxerga o menu Usuários e pode liberar acesso ao sistema para outras pessoas, definindo usuário e senha para cada uma. Todo usuário criado tem acesso completo ao mesmo sistema (mesma Base de SKUs e Listas) — não existem permissões diferentes por página, apenas quem pode gerenciar os próprios usuários (administradores) e quem não pode.

🗓️ Campanhas do mês

Na aba Campanhas do mês, carregue a planilha OFFERS CALENDAR (.csv ou .xlsx; arquivos com uma aba por mês são lidos por inteiro, e dá para carregar vários arquivos de uma vez). Escolha o mês e o ano nos seletores (os que têm ✓ já têm planilha carregada). O sistema analisa cada campanha (produtos, marca, linha, nº de peças) e sugere o SKU pelo padrão do sistema, já no modo "menor SKU possível" (dá para desligar ali na barra). Ele padroniza o código da planilha (3P vira 3PC, tira o "&" e o marcador de promoção), usa o nº de peças da lista de produtos (válvulas não contam) e confere na Base de SKUs e entre as próprias sugestões do mês, então nenhum SKU sugerido repete um existente. A Composição calculada pelos produtos (SH, MSK, TN…) só entra no SKU se você marcar o check 🧬 Usar Composição (desligado por padrão). Se o SKU que a planilha usa já está cadastrado, a campanha aparece como ♻️ reutilizar (e mostramos um código livre só como alternativa, caso seja um kit diferente). Abaixo de cada SKU aparecem as observações do que foi ajustado ou merece conferência. As peças de cada kit são contadas pela lista de produtos (respeitando quantidades como "2 SHAMPOO" ou "MASK x2" e ignorando válvula, sacola, embalagem e amostra); se o SKU da planilha indicar outro número, aparece ⚠️ diverge e o sistema usa a contagem da lista. O ID de cada campanha também é conferido (repetido, fora de sequência, sem ID ou não numérico), e o mesmo SKU usado em kits diferentes é sinalizado. Em qualquer campanha você pode inserir o SKU manualmente (✏️), e ele também pode ser reservado com Vou usar. Quando aparecer ⛔ Sem código livre, use o botão 🧬 Forçar geração com composição: ele gera o código completo do padrão (composição + família), sem o "menor SKU possível". O sistema nunca acrescenta sufixos numéricos (-V2, -V3…): para diferenciar, ele só usa partes reais do padrão (descritor, família DUO/TRI/FULL e, se você marcar o check, a composição); se mesmo assim não houver código livre, a campanha aparece como ⛔ Sem código livre para você decidir.

📏 Peso e volume fora do SKU

Por padrão, nenhum SKU gerado leva peso ou volume (g, ml, kg, L): nem no gerador, nem nas sugestões de campanha. Se um dia precisar, existe o check 📏 Incluir peso/volume (no gerador e na aba Campanhas do mês).

✔ "Vou usar" e 🔔 alerta de promoção

Em cada SKU novo sugerido na aba Campanhas do mês há o check Vou usar. Ao marcar, o SKU é gravado na Base de SKUs (com seu nome e a hora) e nunca mais é sugerido, nem em outras promoções. Desmarcar libera o código. No menu lateral, abaixo do Guia Rápido, o alerta mostra a próxima promoção e quanto tempo falta, e o que está no ar agora, usando as planilhas carregadas. Os horários da planilha são de Nova York.

Backup e uso em vários dispositivos

Esta base (e a lista de usuários) fica salva apenas no navegador deste computador/dispositivo (localStorage) — não é sincronizada automaticamente entre pessoas. Use os botões ⬇ Backup e ⬆ Importar no rodapé do menu lateral para transferir manualmente tudo (SKUs, listas e usuários) para outro dispositivo.

Sobre o login

A tela de login é uma camada básica de acesso local (as senhas são comparadas por hash, não em texto puro, e há bloqueio temporário após 5 tentativas erradas). Ainda assim, isso não substitui uma autenticação real de servidor — não use esta base para dados que exijam segurança forte sem antes implementar um backend próprio.
